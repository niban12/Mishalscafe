# Contributing

- Keep the project dependency-free unless a clear need is documented.
- Preserve static-site deployment.
- Do not invent business claims, reviews, opening hours, prices or contact details.
- Label illustrative data and demo-only interactions.
- Never commit credentials, secrets, personal data or private business information.
- Test responsive layouts and changed interactions before submitting a pull request.

Please describe the change, how it was tested, and any content/assets that need verification.
